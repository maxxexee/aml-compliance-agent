An autonomous AML compliance agent that runs inside Terminal 3's Trusted Execution Environment. R3nzo never sees your data. It only sees risk.

Key benefits
  • Zero PII exposure. The agent never sees wallet private keys, user IDs, or raw transaction data.
  • Instant verdicts. APPROVE, REVIEW, or BLOCK in under 200ms.
  • Plug-and-play API. One POST request to check any wallet. No complex integration.

How it works

Three steps to compliance

R3nzo turns complex AML workflows into a single API call.

01

Submit wallet address

Send a wallet address to R3nzo via API or web dashboard. No user data required, just the public address.

02

TEE runs compliance

R3nzo checks sanctions lists, analyzes on-chain patterns, and calculates risk scores, all inside the secure enclave.

03

Get verdict + audit

Receive APPROVE/REVIEW/BLOCK verdict with full risk breakdown and immutable audit receipt.
